# 코인 시장 위젯 1.3.0

금일·09시 전·중장기 세 분류를 서로 다른 규칙으로 분석합니다. 종목·분석·시장·설정·새로고침을 위젯 안에서 사용하며 앱은 홈 화면 앱 아이콘으로 엽니다. 계정 연결·자동주문 기능은 없습니다.

## 실제 변경점

- 금일: 완료 시간봉의 상승 추세와 BTC 상대강도, 최근 15분 거래 증가를 확인합니다.
- 09시 전: 금일 통과 목록의 하위 집합이던 방식을 폐기했습니다. 직전 1시간 가격 압축, 상단 접근, 최근 15분 거래 가속을 독립적으로 평가합니다. 목적은 9시 전 선매수 후 9시 이후 상승 시 매도 검토입니다. 유효 검토 시간은 08:30~08:55 KST입니다.
- 중장기: 기존 30일 강도에 90일 수익률·BTC 상대강도를 추가하고 변동성 대비 강도로 정렬합니다. 20·60·120일 추세, BTC 추세, 거래대금과 추격 거리를 확인합니다. 1~3개월의 기술적 평가이며 사업가치·뉴스·토큰 발행 일정은 평가하지 않습니다.
- 더 낮은 가격에 살 수 있다고 가정한 진입 구간을 제거했습니다. 실제 조회 가격에서 수수료와 슬리피지를 차감한 지지·저항 여유를 계산합니다.
- 차트 규칙 통과와 과거 수익 검증을 분리합니다. 검증에 미달하면 관찰 순위는 보여 주지만 검증된 매수 추천으로 표시하지 않습니다. 점수는 상승 확률이 아닙니다.

## 수집·갱신

유의·주의 및 스테이블코인을 제외하고 24시간 거래대금 50억원 이상 중 상위 최대 30개 종목을 분석합니다. 시간봉 80개, 5분봉 30개, 일봉 160개를 요청하며 계산에는 완료 봉만 사용합니다. 거래가 끊겨 필수 연속 봉이 없으면 분석하지 않습니다. 금일 최대 30개, 09시 전·중장기 최대 15개를 표시하고 검증에서 평가하는 통과 목록은 상위 5개입니다.

공개 API 새로고침은 조회 시세이며 실시간 호가 스트림이 아닙니다. 금일·중장기는 5분, 09시 전은 2분 뒤 이전 분석으로 표시합니다. 9시 전 목록은 08:58 이후에도 이전 분석으로 바뀌고 09시에는 마감됩니다. 자동 조회는 15분 및 매일 08:30·08:50이며 Android 절전·통신 상태에 따라 늦어질 수 있습니다. 각 분류의 실패 상태와 원래 자료 시각을 따로 보존합니다. 시세 만료를 다시 그리는 작업도 OS에 따라 지연될 수 있으므로 화면의 분석 시각을 확인하세요.

환율은 ECB 일일 발표값입니다. 발표일과 앱에서 확인한 시각을 따로 표시합니다. 새 발표가 없으면 새로고침해도 발표일·값이 같습니다. 통신 실패는 이전 값으로 표시하며 종목 조회 실패가 성공한 환율 갱신을 되돌리지 않습니다.

## 검증 방법

고정 후보: `research/v130/protocol.json`, `candidate-freeze.json`, `StrategyV130.java`. 새 후보는 결과 계산 전 별도 커밋으로 보존했습니다. 앱과 과거 재현은 같은 Java 계산 코드를 사용합니다. 기준이나 평가 날짜를 결과에 맞춰 다시 고르지 않습니다.

단기는 2026-08-25~09-14 기준 구간과 09-18~10-07 평가 구간을 나눕니다. 3일 간격을 둡니다. 금일은 10·14·18·22시 판단, 5분 뒤 시가 매수 후 1·2·4시간 뒤 시가 매도입니다. 09시 전은 08:50 판단, 08:55 시가 매수, 09:05·09:15·09:30 시가 매도입니다. 장중 최고가 매도 가정은 없습니다.

중장기는 2025-01~04와 2025-08~2026-01 구간을 나누고 3개월 간격을 둡니다. 09시 판단 다음 날 시가 매수, 30·60·90일 후 시가 매도입니다. 과거 09시 틱을 확보하지 못해 하루 지연 진입으로 근사한 점을 명시합니다.

매수·매도 각각 수수료 0.05%와 슬리피지 0.05%를 가정하고 편도 슬리피지 0.10%에서도 확인합니다. 같은 시각의 BTC·유동성 비교군 및 현금과 비교합니다. 단기는 날짜 단위, 중장기는 90일 블록 단위 재표집으로 불확실성을 봅니다. 실제 계좌 수익률이나 연환산 수익률이 아닙니다. 과거 상폐·유의 이력과 일부 분봉 시세에 근사가 있으며 이전 작업에서 2026년 자료 일부를 이미 보았으므로 완전히 새로운 미래 검증은 아닙니다.

최종 수치와 세 분류별 판단은 앱의 ‘검증·설명’과 배포 검증 보고서에 기록합니다. 데이터 누락은 숨기거나 0% 수익으로 채우지 않습니다.

## 사용법과 실행 검사

위쪽 분류 선택 → 종목을 눌러 분석 → 아래 목록으로 복귀. 설명은 이전·다음으로 넘깁니다. 주요 버튼 높이 52dp, 검증·설명 버튼 48dp. 위젯을 길게 눌러 홈 화면 점유 크기를 조절하세요. API 키 입력은 앱 설정에서만 가능합니다.

`bash tests/run_tests.sh`: 지표·독립 전략·비용·시각·봉 누락·구문·리소스 검사.
CI: release 빌드, lint, Android API34/36 설치·위젯 터치·크기·갱신·실제 공개 API 조회. 개인 서명키는 저장소·CI에 올리지 않습니다.
