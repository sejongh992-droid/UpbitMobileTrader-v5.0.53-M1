# 코인 시장 위젯 1.2.2

홈 화면에서 세 추천 목록과 분석을 모두 읽는 Android 위젯입니다. 앱·브라우저를 여는 터치는 없으며 앱 아이콘으로만 앱에 들어갑니다. 계정 연결이나 자동주문은 없습니다.

- 금일 추천: 시간봉 상승 추세와 최근 완료 15분의 상승·거래대금 증가.
- 09시 전: 9시 전에 매수하고 직후 급등 시 매도를 검토하려는 목적의 조건 후보. 08~09시 이외에는 다음 09시의 예비 목록, 해당 09시 이후는 진입 추천 종료.
- 중장기: 1~3개월 관점에서 완료 일봉 20·60·120일 추세와 30일 BTC 상대강도, 7일 거래대금으로 선별. 가치평가·뉴스·토큰 일정 분석은 없음.

종목을 누르면 선정 이유, 매수 검토 가격대, 과거 고점, 무효 조건, 수치와 자료 시각을 위젯 안에서 페이지로 읽습니다. 시장 버튼은 BTC 확대 차트와 실제 도미넌스 기록을 엽니다. 하단 설정에서 자동 조회를 전환합니다. 선택적 API 키 입력은 앱 설정을 이용합니다.

## 갱신과 유효시간

- 새로고침: 공개 API에 새 요청. 거래소 체결가 조회이며 실시간 호가 스트림 아님.
- 자동: 15분 + 매일 08:30·08:50 KST. JobScheduler 기반, 절전·네트워크·OS로 지연 가능.
- 분석 목록은 계속 표시. 5분 뒤에는 이전 분석으로 표시하고 매수 가격대는 숨김. 09시 전은 해당 09시 이후 마감 표시. 화면 재그리기는 OS 지연 가능하므로 표시된 조회 시각을 함께 확인.
- 과거 캐시는 이전 분석으로 표시하며 현재 매수 신호로 사용하지 않음. 데이터 실패 시 이전 분석을 유지하고 실패 상태를 표시.
- 환율은 ECB 일일 발표값: 발표 기준일과 실제 성공 조회 시각을 분리. 새 발표 전에는 날짜·값이 같아도 조회 시각은 갱신됨. 실패 시 이전 값 표시. 실시간 환전율 아님.

## 1.2.2 수정

- 환율·업비트·도미넌스 조회의 시간 제한을 분리하고 환율을 먼저 저장합니다. 종목 조회가 실패하거나 취소되어도 이미 성공한 환율 조회는 남습니다.
- 세 목록에 각각 분석 시각과 완료/부분 실패 상태를 기록합니다. 특정 목록 전체가 통신 오류로 비면 이전 관찰 목록과 원래 시각을 보존하지만 조건 충족/진입 구간은 비활성화합니다. 정상적인 자료 부족은 이전 종목으로 채우지 않습니다.
- 환율 확인 시각에 날짜도 표시합니다. 새로고침 중에는 환율 확인/종목 분석/비중 확인 단계를 표시합니다.
- 상단 48dp ‘검증·설명’ 버튼에서 실제 검증 결과와 사용법을 페이지로 읽습니다. 하단 네 버튼과 세 분류는 위젯 안에서 작동합니다.
- ‘매수 조건 충족’을 ‘차트 조건 충족’으로 정정합니다. 점수/선별 규칙은 변경하지 않았습니다. 09시 전 보조 검증과 중장기 근사 재현에서 수익 우위가 확인되지 않았으며, 통과 조건은 수익 확률이 아닙니다.

검증 결과(2026-10-09): 자동매매 관찰 기록의 23일 보조 검증에서 09:15 청산 355건 평균 -0.04%. 중장기 137개 관찰일의 관심 목록 날짜별 평균은 30일 -10.38%, 60일 -17.09%, 90일 -20.47%. 매수·매도 각각 수수료 0.05%, 슬리피지 0.05% 가정. 전자는 위젯 전략 전체 재현이 아니고 후자는 과거 종목 이력/09시 시세에 근사가 있으며 보유 기간이 중복됩니다. 실제 계좌 수익률이 아닙니다.

## 1.2.1 수정

15분 자동 조회 사이 5분 만료로 화면이 비던 문제 수정. 세 목록 모두 검증된 분석 종목을 먼저 보여 주고 조건 충족/관찰로 구분. 시장 방어 조건은 매수 조건을 차단하되 관찰 목록을 지우지 않음. 단기 검증은 관찰 상위 종목도 수행하며 중장기 분석은 시장 약세여도 수행. 하단은 목록·시장·설정·새로고침 네 버튼으로 고정. 종목 상세는 핵심 변화율·조건 상태·부족한 이유를 먼저 표시.

관찰은 상승 보장이나 매수 추천이 아니다. 아래 엄격한 조건은 차트 조건 충족 표시를 위한 기준이며, 모든 관찰 종목이 이 조건을 통과한 것은 아니다.

## 선별 기준 (경험적 규칙; 수익성/상승 확률 검증 모델 아님)

금일: 최대 60종목 완료 시간봉 분석. 기본 유의·주의 제외, 24h 거래대금 50억원 이상, 2분 이내 체결. 현재가≥20h 평균≥60h 평균 및 20h 평균 상승, 6·12h 양의 수익률, 6h BTC 대비≥0.3%p, 최근 1h 거래대금≥이전 20h 평균의 1.1배, RSI 45~68, 시간봉 ATR≤3.5%, 과도한 추격과 불리한 지지·저항 구조 제외. 추가로 최대 30종목 완료 5분봉을 검사, 최근 15분 +0.15~+3%, 직전 60분 평균 대비 거래대금≥1.3배, 최근 3봉 중 양봉≥2. BTC 하락·급락 또는 원화 알트 상승비율 35% 미만은 방어 조건. 최대 30개 표시.

09시 전: 금일 기준에 RSI≤66, 상대6h≥0.5%p, 과거 고점·저점까지 거리비≥1.5를 추가. 최대 15개. 9시 자체를 상승 신호로 쓰지 않으며, 9시 급등 확률을 예측하거나 자동매매하지 않음.

중장기: 관찰 분석은 24h 거래대금 50억원 이상 상위 최대 30종목. 조건 충족 판정은 100억원 이상, 완료 일봉 125개 이상 연속. 현재가≥20일>60일>120일 평균, 60일 평균 상승, 30일 상승 및 BTC 대비 강도≥0, 최근7일 평균 거래대금≥직전21일 평균, RSI45~68, 일봉 ATR≤8%. 과도한 추격과 불리한 가격 구조 제외. BTC 일봉 하락 또는 판단불가면 보류. 최대15개.

참고 진입 구간·무효 저점·과거 저항은 측정값이며 보장된 매수가·손절 체결가·목표가가 아닙니다. 점수는 상승 확률이 아닙니다. 실시간 선별 점수에 수수료·슬리피지·호가·뉴스는 포함하지 않습니다. 별도의 과거 검증은 위의 비용 가정을 사용했으며 실전 수익성을 입증하지 못했습니다.

## UI 및 검증

주요 버튼 높이 52dp. 가로·세로/폴더블 크기 목록을 사용하는 RemoteViews, 미지원 런처는 세로에서 최대 높이를 사용. 위젯의 실제 홈 화면 점유 크기는 런처에서 길게 눌러 조절합니다. 개인 서명은 저장소·CI에 올리지 않음.

`bash tests/run_tests.sh` : 지표·새 전략 규칙·시간 경계·구문·리소스 검사.
CI: release build/lint, Android API34/36 설치·실행·위젯호스트·크기·터치·공개API 갱신.
