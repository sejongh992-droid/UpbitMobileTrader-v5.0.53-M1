# 코인 시장 위젯 1.0.1

안드로이드 홈 화면 조회 전용 위젯. 업비트 자동매매 앱과는 별도 패키지입니다.

- 비트코인 현재가·일봉, BTC 도미넌스, USD/KRW 기준 환율
- 2시간 작업 예약 및 수동 새로고침
- 실제 데이터 기반 규칙 요약 및 관찰 후보. 급등 예측·수익률 보장이 아닙니다.
- 업비트 개인 키 불필요. 선택 입력은 CoinGecko Demo 키 전용입니다.
- 도미넌스 차트는 설치 후 수집한 기록입니다. 24시간 비교도 수집 후 가능합니다.

이 브랜치는 기존 main을 수정하지 않습니다. CI는 공개 API만 조회하며 주문/계좌/출금 기능은 없습니다.
CI release APK는 테스트 인증서로 서명됩니다. 최종 배포 APK는 별도 개인 서명으로 다시 서명합니다. 개인 서명키는 이 저장소에 올리지 않습니다.

검사: 순수 Java 합성 회귀 검사, Android compile/lint, Android 14/16 에뮬레이터 설치 및 위젯 호스트/설정/암호화 저장/동시 조회 방지, 실제 API 수동 조회. 검사 성공 여부는 실제 Actions 결과로 확인해야 합니다. 삼성 실기·2시간 실제 경과·장시간 절전은 별도 점검 대상입니다.
